# event_1 착수 기록

2026-11-18

## 작업 공간

- Worktree는 Codex 관리 이름 규칙에 맞춰 `event-1`에 만들었다. 기준은 로컬에 있는 `origin/main`의 `804755b`다.
- 작업 브랜치는 `feat/event_1`이다. 현재 기획은 같은 폴더의 [plan.md](plan.md)에 복사했다.
- C 드라이브의 확인 시점 여유 공간은 약 2.5GiB다. 원본의 `.next`가 약 2.0GiB이고, 기준 브랜치의 추적 파일은 약 195MiB다. 이번에는 의존성 설치나 캐시 정리 없이 체크아웃과 문서만 준비했다.

## 착수 확인

| 항목      | 확인 결과                                                                                                                                                                                                |
| --------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 도메인    | Cloudflare 프록시와 로컬 Wrangler의 Worker·경로 쓰기 권한을 확인했다. `/event_1` 연결용 Worker를 설치하고 확인 URL의 200 응답을 검증했다. 행사 앱 주소 지정은 배포 후 진행한다. [도메인 기록](domain.md) |
| 행사 DB   | Supabase의 `hometogether-dongduk-landing` 프로젝트에 행사 전용 `event_1` 스키마와 서버 계정을 만들었다. 로컬 DB에서도 같은 스키마와 기존 접수 보존을 검증했다. [접수 API 기록](intake-api.md)            |
| 운영 결정 | 행사 종료일, 개인정보 수집·이용 동의 문구, 보관 기간은 확정이 필요하다.                                                                                                                                  |
| 알림톡    | 연결된 NHN 채널의 템플릿 34개를 조회했고 이번 이벤트 전용 템플릿은 확인되지 않았다. 아래 초안으로 사용자가 직접 등록과 검수 신청을 진행한다.                                                             |
