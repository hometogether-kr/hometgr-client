## 6. 수용 기준과 검증

수용 기준은 사용자가 관찰할 수 있게 적는다. 테스트의 기대 결과는 구현 코드가 아니라 확정 정책에서 가져온다.

| ID    | 사전 조건 | 사용자 행동·입력 | 기대 결과 | 정책 근거 | 검증 방법                     | 실제 결과·증거 |
| ----- | --------- | ---------------- | --------- | --------- | ----------------------------- | -------------- |
| AC-01 |           |                  |           |           | 자동 테스트 / 브라우저 / 수동 | 미실행         |

Codex가 정상·경계·실패 케이스를 제안하고 PM은 제품 정책이 불분명한 기대 결과를 확정한다. 매퍼·URL 파싱/직렬화·포맷 유틸·Zod 스키마를 바꾸면 관련 자동 테스트를 계획한다. 테스트 환경이 없으면 검증 방식과 최소 환경 도입 범위를 먼저 정한다. 컴포넌트 렌더 테스트는 요청 시에만 만든다.

| 린트        | pnpm lint                         | 미실행 |                       |
| 포맷        | pnpm format:check                 | 미실행 |                       |
