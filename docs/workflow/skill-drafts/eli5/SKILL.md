# 쉬운 설명

- 대상은 프론트 구현 경험이 있고 백엔드·인프라에는 익숙하지 않은 PM이다. 설명을 요청한 개념에 집중한다.
- 비유 하나 → 실제 동작 → 홈투게더에서 확인한 사용 지점 → 이 개념을 모르면 잘못할 수 있는 판단 순서로 설명한다.
- 기본은 15줄 이내다. 비유 때문에 실제 제약이 가려지면 그 차이를 한 줄 덧붙인다.
- 저장소에서 확인한 사용 지점에는 파일 링크를 붙인다. 실제 적용을 확인하지 못했다면 `확인 안 됨`으로 표시하고 가상의 적용 예시와 구분한다.
- 개념 설명만 필요하면 불필요한 저장소 전체 조사를 하지 않는다. 현재 제품·API 정보는 실제 문서와 구현을 확인한다.
- 설명 요청을 코드 수정으로 확대하지 않는다. 사용자가 상세 설명을 요청하면 분량을 늘릴 수 있다.
