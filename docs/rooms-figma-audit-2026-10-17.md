## 차이의 원인과 결정이 필요한 범위

아래는 실측 차이에 대한 설명이다. 승인된 수정 목록이 아니며, 기록이 확인되지 않은 항목은 현재 구현을 유지한다.

1. **목록이 위로 올라오는 현상**
   - Figma 필터 영역은 상단 패딩 36px와 기본 상태의 초기화 버튼 행을 포함한다.
   - 구현에는 상단 패딩이 없고, 초기화 버튼은 필터가 활성화됐을 때만 나타난다.
   - 정렬 바 아래 간격도 16px 대신 24px다.
   - 수정 시 기본·필터 적용 상태 모두 기준을 정하고, 초기화 버튼 표시 조건을 함께 검토해야 한다. 카드에 임의의 상단 마진만 추가하는 방식은 피한다.

2. **카드 전체 높이**
   - Figma 비회원 카드 메타데이터는 높이 362px, 회원 카드는 391px다.
   - 현재 실제 매물은 부제목이 두 줄이라 카드 높이가 약 396px다. 한 줄 부제목이라면 현재 CSS상 약 373.5px다.
   - Figma 하단 텍스트에는 텍스트 박스 상하 여백을 줄이는 설정이 있다. 문구 길이·회원 배지·텍스트 박스 조건이 달라 전체 높이를 단순한 고정 수치로 맞추면 안 된다.

3. **회원 카드의 정보 배지**
   - 회원 Figma에는 성별, 건물 유형, 최대 입주 인원 배지가 있다.
   - 현재 `RoomCard`는 회원 여부에 따른 배지 분기가 없고, 목록용 `Room` 모델에도 해당 표시용 필드가 없다.
   - 이를 반영하려면 표시 정책과 API 응답 매핑을 확인해야 한다. 단순 크기 수정으로 묶지 않는다.

4. **색상과 검색창 내부 치수**
   - 탐색 페이지 배경, 건수 색상, 검색 버튼 클릭 영역, 검색창 내부 패딩은 변경 의도 확인 후 조정 여부를 정한다.
   - 검색 위젯은 메인에서도 공유하므로 탐색 레이아웃에만 적용해야 한다.
   - 부제목은 위치만 옮긴 현재 요청을 우선한다. 기존 주소 스타일로 바꾸는 것은 별도 결정이다.

5. **공통 헤더**
   - 지정된 Figma 화면과 현재 헤더의 로고 크기·메뉴 구성이 다르다.
   - 실제 헤더는 별도 디자인 노드와 게스트·집주인 모드 정책을 사용하므로, 과거 탐색 화면의 헤더만 기준으로 전역 수정하지 않는다.

## 기능·정책상 차이 및 검증 한계

- Figma는 자유 검색·최근 검색어를 표현하지만, 현재는 합의한 지역구 선택·X 초기화 흐름이다. 이번 실측을 이유로 되돌리지 않는다.
- Figma의 보증금·월 이용료·이용 인원 필터와 현재 구현은 차이가 있다. 최종 제외 결정의 Markdown 근거는 확인하지 못했으므로 ‘승인된 제외’로 단정하지 않으며, 이번 디자인 비교를 이유로 추가하지 않는다.
- 비회원 기본 프레임과 회원 프레임의 카드 높이·행 간격이 서로 다르다. 모든 상태를 하나의 고정 카드 높이로 맞추는 기준은 아직 확정되지 않았다.
- 필터 모달·빈 결과 화면·정렬 드롭다운 내부의 전체 실측 검증은 이번 초기 목록 비교에 포함하지 않았다.
- 상세·예약 화면, 월세 단위, 마이페이지는 변경하지 않았다.
- 현재 공개 매물의 제목 → 가격 → 부제목 순서를 브라우저에서 확인했다. 390px 모바일에서도 부제목이 두 줄로 표시되고 페이지 가로 넘침이 없었다.
- 문서의 디자인 차이는 아직 수정하지 않았다. 부제목 이동만 구현했다.
- 수정한 카드 파일의 ESLint·Prettier 검사와 `git diff --check`를 통과했다. 커밋·배포는 진행하지 않았다.

## 후속 승인: 탐색 페이지 세 가지 치수 조정

사용자가 검색 버튼 클릭 영역 40×40px, 검색창 왼쪽 여백 20px, 정렬 바와 카드 간격 16px를 승인했다. 나머지 디자인, 검색 동작, 월세·마이페이지는 변경하지 않았다.

- `RoomRegionSearch`의 `explore` 분기에만 버튼 크기와 왼쪽 패딩을 적용했다. 아이콘은 24×24px, 오른쪽 패딩은 기존 값으로 유지했다.
- 탐색 목록에서만 사용하는 `RoomListToolbar`의 하단 여백을 24px에서 16px로 변경했다.
- PC 1920×1080 및 모바일 390×844 브라우저 실측에서 버튼 40×40px, 왼쪽 패딩 20px, 정렬 바와 첫 카드 간격 16px를 확인했다. PC 첫 카드 y는 약 425.4px다.
- 메인 검색창은 기존 코드 분기를 유지하며, PC에서 너비 473px·검색 버튼 90×56px·입력 왼쪽 패딩 20px·버튼 사이 간격 8px를 확인했다. 모바일은 검색 버튼 90×56px·왼쪽 패딩 12px·버튼 사이 간격 8px로 기존 값과 일치했다.
- 모바일에서 탐색·메인 모두 문서 너비와 스크롤 너비가 375px로 같아 페이지 가로 넘침이 없었다.
- 변경한 두 파일의 ESLint(경고 허용 0)·Prettier 검사 및 `git diff --check`를 통과했다.
- 검증용 개발 서버는 종료했으며 기존 개발 환경과 캐시는 유지했다. 커밋·배포는 진행하지 않았다.
