## 에셋과 원문

사진·SVG는 섹션별 디자인 컨텍스트와 스크린샷을 대조했다. 정적 에셋을 임시 Figma URL로 렌더링하지 않는다. 현재 서비스 소개의 합성 사진 세 장은 문구가 바뀌어 새 원본을 사용하며, 동일한 지역 사진과 아이콘은 기존 `guest-landing` 파일을 재사용한다. 신규 에셋 29개는 모두 사용 중이며, 같은 내용으로 내려받은 아이콘 5개(약 4.5KB)는 기존 파일을 재사용하도록 정리했다. 공감 인물 PNG의 출처는 Figma 구성 설명에 명시된 Microsoft Fluent Emoji(MIT)다.

FAQ 메인 6문항의 질문·요약·본문을 Figma와 대조했다. 전체 22개 원문은 기존 `pages-layer/guest-home/model/faq-content.ts`와 동일하며 별도 신한 slice의 모델에 둔다. 일반 게스트 slice를 직접 import하지 않는다. Figma 대표 번호에 맞춰 기존 21번(거주 중 불편)을 22번으로, 기존 22번(계약 연장·퇴실)을 21번으로 매핑했다.

후기 영상은 Figma 원본 링크 `https://www.youtube.com/shorts/O8bQe1yCjOM`를 사용한다. 소개의 ‘한 학기(4개월)’ 문구와 운영·후기 내용은 시안 원문이며, 이번 작업에서 실시간 조건으로 조회한 값이 아니다. 후속 신청의 계약기간 선택은 확정된 1~12개월과 별도 ‘12개월 이상’을 따른다.

## 단계 범위와 남은 차이

- 예산 배너·고정 CTA와 위치·지역·방 둘러보기 CTA를 구분했다. 하위 신청은 이번 범위가 아니므로 비활성 버튼과 준비 중 안내를 표시한다. 입력값 전달·폼·실제 저장·완료 처리를 구현했다고 표시하지 않는다.
- 개인정보 전문은 공통 신청 기반 단계에서 연결한다.
- 게스트 고정 CTA는 공감 제목이 보이거나 이미 지나갔을 때 표시하고, 상단으로 돌아가면 숨긴다. 본문 동일 예산 CTA가 보이는 동안 중복 고정 버튼을 숨긴다. 호스트의 ‘처음부터 표시’ 결정을 게스트에 확대하지 않았다.
- 원본 플로팅의 예산·지역·입주일 입력은 후속 신청 단계로 남긴다. 이번에는 진입 안내와 접기/펼치기만 구현한다. Figma 반복 모션은 적용하지 않았다.
- 1888px 이상에서 오른쪽 320px 안내 패널을 사용한다. 원본 340px에서 줄인 것은 1200px 본문과 겹치지 않게 하기 위한 배치 조정이다. 작은 PC·태블릿·모바일에서는 하단 CTA 하나로 대체하고 안전 영역과 하단 여백을 확보한다.
- 모바일은 768px 미만 1열·좌우 20px·문구 다음 관련 사진·세로 후기와 FAQ를 적용한다.
- 전체 FAQ와 필터는 화면 안에서 동작한다. 새 신청·저장·외부 전송을 발생시키지 않는다.

## 검증

개발 서버는 `http://127.0.0.1:3000`이며 기존 의존성과 `.next` 캐시를 재사용했다. 브라우저에서 실제 페이지와 주요 상호작용을 확인했다.

SVG 히어로의 소수점 intrinsic height로 발생하던 Next.js 크기 경고는 정수 높이와 CSS 자동 비율로 수정했다. 기존 다중 lockfile로 인한 Turbopack root 추론 경고는 환경 변경 없이 기록했다. 개발 서버만 재시작했으며 캐시를 삭제하지 않았다.

검증 스크린샷은 Codex 작업 첨부 경로의 `shinhan-guest-desktop-full.jpg`, `shinhan-guest-mobile.jpg`, `shinhan-guest-mobile-empathy.jpg`에 남겼다.

실제 휴대폰·Safari·신한 앱 내 웹뷰와 운영 환경 검증은 이번 로컬 단계에 포함하지 않는다. 서버·DB·관리자 코드를 수정하거나 운영 배포하지 않는다.
