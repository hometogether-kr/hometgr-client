## 변경

- 호스트 고정 월세 진단 CTA의 무조건 금지 커서를 수정했다. 활성 상태는 pointer, 실제 비활성 상태만 not-allowed다. 신청 가능 여부와 BFF 보안 가드는 유지한다.
- 네 신청 유형과 개발 미리보기에서 공유하는 개인정보 동의 영역을 체크박스와 인접 전문 보기 1개로 정리했다. 별도 신청 준비 버튼, 중복 전문 링크·버전 요약을 제거했다. 동의를 요구하지 않는 기존 신청 내역·가이드의 전문 링크는 유지한다.
- 서버 동의 전문은 Query를 통해 자동 조회한다. 조회만으로 익명 세션이나 신청을 만들지 않는다. 조회 실패 시에만 작은 재시도 안내를 표시하며 준비되지 않은 전문으로 제출하지 않는다.
- 체크한 전문 버전을 초안에 연결한다. 전문 왕복·일반 재렌더링으로 동의를 초기화하지 않으며, 다른 버전으로 바뀌면 재동의를 요구한다.
- 신청 버튼을 누르면 입력 검증 뒤 세션 발급·재사용과 신청 전송을 이어서 진행한다. 대기 전에 입력과 UUID를 고정하고, 응답 유실 재시도 시 같은 CSRF·본문·키를 유지한다. 기존 다중 탭 잠금과 명시적 세션 재시작을 유지한다.
- 방 등록 버튼 하단의 겹치는 문구를 하나로 정리했다: “신청 후 접수 내역을 확인할 수 있어요. 입력하신 정보를 검토한 뒤 심사 결과를 안내해 드릴게요.” 접수 성공을 알림톡 전달 완료로 표현하지 않는다.
- 동의 행은 좁은 폭에서 문구가 줄바꿈되어도 전문 링크가 옆 열에 유지되도록 구성했다. 실제 PC·모바일 렌더링 확인은 아래 미완료 항목으로 구분한다.
