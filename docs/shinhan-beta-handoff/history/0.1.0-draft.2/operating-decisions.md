## 3. 그대로 유지하는 기존 확정 사항

- 기존 고객 화면·입력·신청·이동·결과 흐름을 유지한다. 새 체험 모드·안내 연결·확인 버튼·제외된 안내문을 추가하지 않는다.
- 시작은 첫 유효 입력·선택 기준이다. 단순 CTA·화면 표시·자동 기본값을 시작으로 세지 않는다.
- HOST_ESTIMATE는 기존 예상 월세 결과 표시, HOST_REGISTRATION은 기존 등록 완료 화면 표시가 완료다.
- GUEST_BUDGET 또는 GUEST_DEMAND 중 선택한 한 흐름 완료 후 기존 걱정 안내를 확인하면 완료다. 자기 역할의 두 흐름을 모두 요구하지 않는다.
- 호스트에게 걱정 안내·소개서·알림 신청을 요구하지 않는다.
- 시작 후 24시간 미완료는 분석상 중단이다. 24시간이 새 시도를 자동 생성하는 기준이라는 뜻은 아니다.
- 익명 분석과 신청 정보를 연결하지 않는다. 금지된 개인정보·신청 ID·세션·비밀값·전체 URL을 넣지 않는다.
- 재시도·새로고침·재조회가 중복 완료를 만들지 않아야 하며, 기록 실패가 고객 행동을 막지 않아야 한다.
- 출처는 기존 utm_links.md를 따른다. 내부 이동·직접 재방문으로 최초/최근 외부 출처를 덮어쓰지 않는다.
