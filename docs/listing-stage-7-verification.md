# 목록 복귀·스크롤 복원

## 구현

- 모든 목록 카드가 정규화한 검색 조건·정렬·누적 page를 상세 returnTo에 전달합니다.
- 실제 상세와 미리보기 상세에서 검색 결과로 돌아갈 수 있습니다. 직접 진입·잘못된 복귀 경로는 /rooms로 이동합니다.
- 더 보기 결과를 현재 URL에 대응하는 쿼리 캐시에도 보관합니다. 캐시가 없으면 첫 페이지부터 URL의 page까지 기존 목록 API로 조회하며 마지막 페이지에서 중단합니다.
- 클릭 직전 카드 ID·카드의 화면 내 위치·스크롤을 sessionStorage에 저장합니다. 매물 데이터·주소·인증 정보는 저장하지 않습니다. 최대 10개, 30분 제한이며 Zod 검증·저장소 오류 처리를 적용했습니다.
- 목록 DOM 준비 및 재조회 완료 후 카드 위치를 복원합니다. 사용자가 휠·터치·키보드로 움직이면 자동 복원을 중단합니다. 필터 변경·초기화는 이전 복원 위치를 제거합니다.
- 목록 재진입은 캐시를 즉시 보여주고 최신 조회를 실행합니다. 조회 실패 안내, 중복 ID 제거, 더 보기와 재조회 경합 방지를 추가했습니다.
- 캐시된 카드가 비공개·삭제되어 상세 API가 404를 반환하면 공개 중단 가능성을 안내하고 검색 조건을 유지해 복귀합니다. 상세 카드 prefetch는 꺼서 클릭 전에 오래된 상세를 미리 보관하지 않습니다.

## 브라우저 검증

- 모의 매물: 지역 UI에서 노원구 선택, 월세 저렴한순, 더 보기로 2페이지 11개 확인.
- 브라우저 뒤로가기: 지역·정렬·page URL과 11개 목록 유지.
- 검색 결과로 돌아가기 링크: 데스크톱 이동 전후 scrollY=1694.4000, 기준 카드 top=158.9000으로 동일.
- 새로고침: page=2에서 첫 페이지의 노원구 1번부터 11개 전체 복원.
- 모바일 390×844: 이동 전후 scrollY=1409.6000, 기준 카드 top=456.3000으로 동일. 가로 넘침 없음.
- 실제 중랑구 공개 매물: 상세 링크에 지역·월세순 유지, 복귀 후 동일 URL·1개 목록·지역/정렬 선택 유지.
- 존재하지 않는 UUID로 실제 상세 조회: 공개 중단 가능성 안내와 기존 중랑구·월세순 목록 복귀 링크 확인.
- TypeScript 전체 검사 및 수정 파일 ESLint 통과.

실제 공개 API는 현재 매물 1개이므로 여러 페이지 복원은 모의 매물로 검증했습니다. 관리자 게시·수정·비공개 전환 자체는 이번 검증에서 실행하지 않았으며 8단계 통합 검증에 남깁니다.
