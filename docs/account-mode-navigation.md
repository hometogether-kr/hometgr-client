# 모드 전환과 내비게이션

작업 브랜치: `feat/account-mode-onboarding-consultation`.

## 적용한 동작

- `/`는 게스트 메인이다. 이전 선택형 첫 화면을 대체한다.
- `/intro/guest`는 `/`로 영구 리디렉션한다.
- 집주인 메인은 `/intro/host`다.
- 두 메인에서는 URL이 저장값 및 서버 role보다 우선한다.
- 두 메인에만 텍스트 전환 링크를 표시한다. 로그인 없이도 이용 가능하다.
- 반대 모드로 전환하면 해당 메인으로 이동한다.
- PC 헤더와 모바일 메뉴는 게스트에서 방 찾기, 집주인에서 방 내놓기만 표시한다.
- 로고 및 서비스 소개 링크는 현재 모드의 메인으로 연결한다.
- 기타 화면에서는 저장된 모드를 사용하고, 유효한 값이 없으면 게스트를 기본으로 한다.
- 회원은 계정별로, 비회원은 방문자 키로 모드를 저장한다. 서버 권한은 변경하지 않는다.
- 직접 진입, 새로고침, 뒤로가기 때도 메인 URL을 기준으로 저장값을 갱신한다.

## 역할 없는 가입

- 카카오 로그인 → 약관 동의 → 기본 정보 확인(`/onboarding/profile`) → 가입 완료 순서로 진행한다.
- 기본 정보는 이름과 연락처이며, 가입 요청에 `role`을 보내지 않는다.
- 기존 `/onboarding/role` 주소는 기본 정보 화면으로 리디렉션한다.
- 로그인 시작 시 모드를 30분 동안 서버 쿠키에 보관하여 가입 완료 후 해당 메인으로 이동한다. 저장값이 없거나 유효하지 않으면 게스트 메인으로 이동한다.
- 기존 회원 로그인도 로그인 시작 시 선택한 모드의 메인으로 이동한다.
- 기존 API 응답의 role과 관리자 권한 판별은 유지한다.

## 별도 후속 작업

상담 폼 연동 및 보류 사항은 `host-consultation-integration.md`에 기록한다. 관리자 UI는 추후 작업이다.

## 수동 점검

1. `/`에서 게스트 소개, 방 찾기, 집주인 전환 링크를 확인한다.
2. 전환 후 `/intro/host`, 방 내놓기, 게스트 전환 링크를 확인한다.
3. 새로고침과 뒤로가기 후 경로와 메뉴가 일치하는지 확인한다.
4. 로그인 화면 등 공통 화면에서 전환 링크가 없고 모드는 유지되는지 확인한다.
5. 모바일 375px에서 전환 링크와 메뉴가 겹치지 않고 동일하게 동작하는지 확인한다.
