## API 계약과 남은 차이

API 기준은 `C:\Users\PC\Documents\GitHub\shinhan\docs\api-contract-v1.md`의 **1.0.0**이다. 이번 단계는 정적 역할 선택 화면으로 API·개발 예시 응답·접수 완료 처리를 추가하지 않았다. 실제 연동 완료를 의미하지 않는다. 다음 연동 단계에서 계약 원본 버전과 변경사항을 다시 확인한다.

- 신청·결과·완료·걱정·가이드·내역 및 전송 계층은 이번 범위에 포함하지 않았다.

## 다음 작업 순서

한 단계마다 구현·PC/모바일 검증·남은 차이 보고를 마치고 다음 작업을 진행한다.

1. **호스트 소개 한 화면**: `/shinhan/host`의 확정 섹션·사진·메뉴·모바일 CTA. 다음 착수 단위로 권장한다.
2. **게스트 소개 한 화면**: `/shinhan/guest`의 확정 섹션·공통 예시 사진·지역 카드·FAQ·모바일 CTA.
3. **신청 공통 기반**: 계약 재확인, DTO/Zod·전송 계층·고객 프론트 BFF·세션·멱등키, 동의 전문, 작성 단계·입력·선택값을 보존하는 전문 열람/복귀. 개발 예시 모드는 운영에서 차단한다.
4. **호스트 방 등록**: 자유 위치 입력부터 실제 저장·완료·조회 전용 내역까지 한 흐름을 검증한다.
5. **호스트 견적·소개서**: 기존 카카오 주소검색·Calendar 재사용, 저장 성공 뒤 서버 견적 표시, 소개서 신청·재시도.
6. **게스트 예산**: 자유 위치, 20–100만 원·1만 원 단위, 1–12개월 및 별도 12개월 이상, 공통 사진·‘찾았어요’ 문구, 저장·완료·조회 전용.
7. **게스트 수요**: 자유 위치 입력과 나머지 계약 필드, 저장·완료·조회 전용.
8. **후속 화면**: 걱정 선택·가이드·신청 직후 내역. 미정 동작은 해당 단계에서 확인한다.
9. **전체 연결 검증**: 실제 로컬 신한 API 저장·실패·중복 제출·재시도·전문 복귀·모바일 전 흐름. 예시 응답 검증과 실제 저장 검증을 구분한다. 운영 배포는 별도 지시가 필요하다.
