# 상담 신청 폼 연동

## 구현

- 집주인 메인 `/intro/host` 상담 버튼에서 비로그인으로 신청 가능.
- 지역 목록: `GET /consultation-regions?type=university|subway&limit=50`. keyword 미사용. API 예시 목록만 표시.
- 대학교는 표시명(학교·캠퍼스), 역은 역명 표시. 같은 역명이 있으면 시·군·구로 구분.
- 대학교 기타 입력: `custom_university`와 `customUniversityName`으로 제출.
- 방 개수 1/2/3개 이상은 1/2/3, 에어컨은 boolean, 주택 형태는 `owned`/`leased_or_rented`로 변환.
- `POST /host-consultation-requests`로 접수. 공통 BFF를 사용하고 로그인은 요구하지 않음.
- 필수값 검증, 제출 중 중복 클릭 방지, 409 중복 안내, 오류 시 입력 유지, 성공 안내 구현.
- 동의 시각과 신청 시각은 서버가 기록하며 프론트에서 임의 생성하지 않음.

## 추후 결정 및 백엔드 요청

- 개인정보 보유 기간은 사용자 요청에 따라 **확정 후 안내 예정입니다.**로 표시.
- 운영 전 수집·이용 문구, 보유 기간, 동의 문구 버전을 확정할 것.
- 현재 버전은 Swagger 예시 `host_consultation_v1`을 사용. 확정 문구와 버전을 함께 갱신할 위치: `src/features/request-host-consultation/config/privacy-policy.ts`.
- 지하철역 기타 제출은 사용자 요청에 따라 보류. 백엔드에 직접 입력 유형·필드 및 동일 연락처+직접 입력 지역 중복 판정 기준 확장 요청 필요.
- 목록 API 최대 50개 제한. 전체 마스터 보강 시 검색 키워드 없이 전체 목록을 제공할 방법(페이지 처리 등) 재협의.
- 관리자 화면은 범위 제외.

## 검증 범위

- API 호출을 모의 처리하여 코드값 변환, 기타 대학교, 기타 지하철역 거부, 필수값, 동의, 409/500/네트워크 오류 및 응답 검증 확인.
- 실제 상담 신청 데이터 생성은 하지 않음. 저장부터 관리자 조회까지의 실제 접수 확인은 별도 점검 필요.
