# 집주인 메인 S5

- 작업 브랜치: `feat/listing-registration-guest-landing`.
- 페이지: `/intro/host`.
- 디자인: [S5 · 진행 방법](https://www.figma.com/design/YnZUb0kkG3K4NdBZspF6wU?node-id=2849-3013).
- 범위: 기존 세 단계 진행 안내를 S5의 네 영역으로 교체. 다른 섹션은 유지.

## 디자인 기준

| 항목                     | 확인한 값                             |
| ------------------------ | ------------------------------------- |
| 화면 / 본문              | 1920px / 1200px                       |
| 섹션 패딩 / 제목 뒤 간격 | 상하 60px / 50px                      |
| 제목                     | Pretendard 700, 48px / 68px           |
| 카드 제목                | Pretendard 700, 28px / 130%           |
| 본문                     | Pretendard 600, 16px / 160%, 자간 -5% |
| 카드                     | 흰 배경, 반경 16px                    |
| 첫 번째 / 세 번째 카드   | 660px                                 |
| 두 번째 / 네 번째 카드   | 540px / 544px                         |

기존 `hostContainer`, Pretendard 로딩, 전역 색상·타이포그래피 토큰을 재사용한다.
본문과 라벨은 HTML로 구현하고, 일러스트와 아이콘만 원본 노드에서 내보냈다.
학생 선택 화면 안의 버튼은 서비스 설명을 위한 일러스트이며 실제 조작 버튼이 아니다.

## 구현 판단과 확인 사항

- 데스크톱의 좌우 교차 배치를 유지한다. 모바일은 설명 다음 이미지 순서로 읽는다.
- 좁은 화면에서는 준비 항목을 2열로 배치하고 안내 배지의 설명을 다음 줄로 보낸다.
- 별도 모바일 S5 시안이 없어 위 반응형 규칙은 구현 판단이다.
- 네 번째 카드 본문은 Figma에 두 번째 카드의 학생 선택 설명이 반복되어 있다.
  임의로 수정하지 않고 원문을 유지했다. 최종 카피 확인이 필요하다.
- 기존 페이지의 다른 섹션과 최신 Figma의 차이는 이번 수정 범위에 포함하지 않는다.
