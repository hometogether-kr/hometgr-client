# 회원 건물 지도 및 배포 API 재대조 기록

2026-10-15 · `feat/listing-exploration-release`

## 계약 근거

- [효재님 회신](https://hometohq.slack.com/archives/C0BTSGN4PHS/p1791979232092019): v2는 `data.location.buildingAddress`, 레거시는 최상위 `buildingAddress`. 도로명 우선·지번 대체, 동·호수·자유 상세주소 제외, 비회원 필드 제외. 좌표 저장 기능 추가 없음.
- [개발 API 배포 명세](https://dev-api.hometogether.kr/docs-json): 위 계약 확인. 미확인·해석 불가 주소는 null. 로컬 백엔드에는 이 필드가 없어 로컬 코드만으로 계약을 판단하면 안 됩니다.
- [카카오 공식 주소 검색 예제](https://apis.map.kakao.com/web/sample/addr2coord/): services 라이브러리의 Geocoder로 건물 주소를 변환합니다.

## 구현

- 회원 공개 DTO의 buildingAddress만 모델로 전달합니다. addressRoad·addressDetail·기존 좌표로 대체하지 않습니다. 비회원은 buildingAddress=null입니다.
- 로그인 상태와 서버 viewerAccess가 모두 회원일 때만 회원 위치 카드를 렌더링합니다.
- 실제 화면과 모의 상세가 같은 위치 카드를 사용합니다. 주소가 없으면 안내만 표시하고 지도 SDK를 요청하지 않습니다.
- 지도는 로딩·실패·재시도를 지원합니다. 검색 결과가 없거나 여러 개이거나 좌표 범위가 유효하지 않으면 표시하지 않습니다. SDK와 주소 검색 각각 15초 제한, 화면 이탈 시 검색 결과 무시·타이머 해제·마커 및 ResizeObserver 정리.
- 높이는 모바일 320px, 데스크톱 440px. 기존 좌표 기반 KakaoMap 호출도 지원합니다.
- 상세 스키마 보완: 레거시 media 누락은 빈 배열, 명세상 선택인 v2 지역·주차 필드는 누락 허용. 잘못된 타입의 값은 계속 검증합니다.

## 남은 확인

- 사용자 요청으로 미룬 실제 OAuth 완료, 유효 refresh token에 의한 회원 상태 복구, 실제 회원 매물의 buildingAddress 수신과 지도 표시.
- 회원→비회원 전환 종단 검증. 컴포넌트 해제·주소 검색 취소 분기는 구현/모의 검증했고 실제 세션 만료까지 검증하지 않았습니다.
- 배포 도메인에서 카카오 지도 허용 도메인 설정 및 지도 표시 확인. 현재 로컬 검증 주소는 `http://localhost:3000`을 사용합니다.
- 명세의 월세 설명·예제는 아직 원 단위지만 실제 공개 응답 30과 사용자 확정은 만원 단위입니다. 현재 표시 정책을 유지하며 백엔드 명세 정리가 필요합니다.
- 레거시 회원 상세 명세에는 media 필드가 없으므로 누락을 허용했습니다. 실제 레거시 회원 사진 응답은 별도 확인이 필요합니다.

백엔드·관리자·외부 서비스 설정은 수정하지 않았으며 실계정 검증 완료로 처리하지 않습니다.
